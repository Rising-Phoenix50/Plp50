1. Team Charter
1.1 Communication Norms
• Primary channel: shared WhatsApp group "PLP group 50". All decisions that affect the whole team are posted with @all so no one can claim they missed them.
• Response window: members respond within the same day; if someone is offline for a known reason (exams, network/power outage), they flag it proactively so the team isn't left guessing 
• Code-switching between English and Swahili in chat is accepted; formal deliverables (charter, board, code, reviews) are written in English.
• Feedback is direct but supportive — technical critique is paired with encouragement, following the tone Josh set in his structural review of the frontend.

1.3 Deadlines
• Team leadership confirmed: within 24 hrs of project kickoff, which was 11th August, 2026 ("before tomorrow 1200").
• Working skeleton in collaborators' hands: as soon as the repo and roles are set, so no one is blocked waiting on delegation.
1.4 Tools & Working Conventions
• Version control: shared GitHub repository; every member added as a collaborator by email invite before writing code.
 Hosting: GitHub Pages, so that any member can review a live link instead of running code locally.
• Project structure: separation of concerns is mandatory — index.html, styles/style.css, scripts/script.js, images/ — no large inline CSS or JS blocks, per the convention.
• Build approach: a mix of hand-coding and AI-assisted ("vibe-coded") drafting — complex pieces are vibe-coded and then reviewed line-by-line before merging; lightweight pieces are hand-coded directly.
1.5 Conflict Resolution & Escalation
• Technical disagreements are resolved by deferring to the audit lead's written review, which lists concrete issues (e.g, hardcoded data, missing interaction flow, unstructured files) rather than general criticism.
• If a member shows zero visible activity for 1 day, Joshua raises it in the group immediately rather than waiting for the deadline, and the team reassigns or splits the task if needed.
• Personal constraints (exams, connectivity issues) are accommodated without penalty as long as they're communicated proactively — the standard the team already held itself to with Adams and Josh.
